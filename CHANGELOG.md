# Changelog

## 0.1.0 — 2026-08-07

Initial TaskTrack implementation.

- Added durable human-verification task model with JSON validation, recovery backups, bounded history, and Markdown evidence export.
- Added compact U++ GUI with objective header, wrapped categories, responsive task-card columns, ten verification input types, pause/resume, reminders, agent-poll nudging, autosave, and export actions.
- Added stdio MCP bridge with durable create/get/open/list/close tools, current 2026-07-28 request handling, legacy initialize compatibility, and optional `io.modelcontextprotocol/tasks` lifecycle support.
- Added examples, deterministic tests, Windows build wrapper, implementation plan, schema documentation, host setup, and Windows acceptance matrix.
